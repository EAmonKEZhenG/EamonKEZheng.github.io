Human vs AI Analysts for Predicting Vancouver Land Value

Overview

This project builds an end-to-end, reproducible land-value prediction system using public Vancouver datasets. The core goal is both practical and methodological: predict land assessment values with robust error control, and compare a human-designed machine learning pipeline against two AI-agent development workflows.

Motivation

Property valuation is strongly affected by location, legal structure, and market conditions, but many pipelines are difficult to reproduce over time. We designed this system to test whether AI-assisted workflows can match the stability and performance of a carefully engineered human pipeline under realistic, time-aware evaluation.

Data Pipeline

  • Cleaned Vancouver property tax records and standardized yearly external datasets.
  • Merged property-level, location, legal type, zoning, mortgage, immigration, study-permit, and rental-supply indicators.
  • Enforced a time-aware split to reduce leakage and simulate forward deployment:
    • Train: REPORT_YEAR < 2024
    • Test: REPORT_YEAR >= 2024

Modeling Methodology

  • Applied a log1p target transformation for better error behavior on high-value outliers.
  • Used train-only target encoding for high-cardinality categorical features, including postal code, neighbourhood code, and legal type.
  • Focused on strict reproducibility: deterministic preprocessing, explicit feature construction, and clear train/test boundary handling.

Human vs AI-Agent Workflows

  • Human Pipeline: manually designed feature engineering and validation strategy with reproducible controls.
  • Mode I: OpenAI Code Interpreter cloud workflow for rapid exploratory modeling and iteration.
  • Mode II: local Claude Code workflow for code-first automation and local experimentation.

The comparison emphasizes not just model score, but also repeatability, clarity of assumptions, and operational stability.

Web Application

We deployed an interactive prediction interface with a React frontend and REST API backend:

  • Precise Mode: structured property-attribute input for deterministic prediction.
  • Fuzzy Mode: address-based search with candidate matching for practical user workflows.

Results

Final human-designed pipeline performance:

  • MAE: 590,973 CAD
  • Median APE: 11.81%
  • Robust MAE: 489,160 CAD

Main finding: detailed local location and property-type signals were substantially more predictive than broad yearly macro indicators.

Lessons Learned

AI agents were highly useful for exploration, iteration speed, and generating alternative solution paths. However, the human-designed workflow remained more stable, reproducible, and accurate under strict temporal evaluation and feature leakage controls.
